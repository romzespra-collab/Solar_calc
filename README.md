# Солнечный калькулятор (solar_calc) v1.11.8

Калькулятор выработки домашней солнечной станции с MPPT и АКБ: сколько реально доходит до АКБ
в ясный / средний / пасмурный день каждого месяца и за год, куда теряется энергия, хватит ли
станции дому и когда придётся переходить на горсеть. Windows 10/11, Python 3.12+, PySide6.

## Запуск

Двойной клик по `solar_calc.pyw` (папку `modules/` держать рядом). PySide6 поставится сам при
первом запуске (откроется окно установки). Проверка без окна: `python solar_calc.pyw --selftest`.

## Что считает

Солнце → угол и азимут → панели → схема S×P → провод и контакты → MPPT → ток заряда → АКБ → инвертор:

- **солнце**: наклон, азимут, тень от горизонта, часовой пояс; данные — встроенные (≈Киев) или
  PVGIS для любой точки;
- **панели**: паспорт, нагрев (NOCT), температурный коэффициент, КПД на слабом свету;
  рассогласование, грязь, «поправка по факту»;
- **провода**: длина, сечение (или диаметр жилы), медь / алюминий, нагрев; контакты MC4 и клеммы;
  участки поле → MPPT, MPPT → АКБ, АКБ → инвертор;
- **MPPT**: макс. Voc, окно напряжений, запас над АКБ, лимит входного тока, КПД (падает при
  большом Vвх/Vакб), собственное потребление, лимит тока заряда;
- **АКБ**: готовые АКБ или ячейки, сборки S×P, ёмкость, лимит тока заряда, холод;
- **инвертор**: модель, КПД, холостой ход, часы работы;
- **дом**: потребление за месяц или за год → баланс по месяцам, автономия АКБ.

## «Моя станция» — конструктор

Вверху страницы ⚙ Настройки — схема станции и шаги ① Инвертор → ② АКБ → ③ Поля панелей →
④ Кабели → ⑤ Дом и сеть (рамка шага: красная — ошибка, жёлтая — предупреждение).

- Во главе инвертор; к его входам MPPT подключены поля панелей — у каждого поля свои панели,
  схема S×P, угол и азимут. Отдельные MPPT-контроллеры со своими полями (до 6) — на линии АКБ;
  до 6 разных сборок АКБ на шине; дом и горсеть.
- Добавлять — правым кликом на схеме: «＋ Поле на свободный вход MPPT инвертора», «＋ Отдельный
  MPPT (прибор) с полем», «＋ Ещё сборка АКБ», «⧉ Копия» поля, «🗑 Убрать».
- **Несколько полей на один вход MPPT** (разные панели, стороны и углы): правый клик по полю →
  «⇄ Вход MPPT» или «＋ Поле параллельно на этот вход». Расчёт — по вольт-амперным
  характеристикам цепочек при общем напряжении; проверки за год: потери против отдельных входов,
  срезка током входа, обратный ток, предохранители.
- Линии схемы — кабели с подписью (сечение, длина, потери), цвет — проверка; клик по подписи —
  настройки кабелей. Узлы можно перетаскивать мышью, места запоминаются; «↺ Вернуть на место» /
  «↺ Расставить всё автоматически».
- Выбор оборудования: панели — производитель → серия → мощность × количество (🔎 поиск по всей
  базе: «risen 330», «tiger 440»); схема по входам MPPT с проверкой ✓ / ⚠ / ✗ и кнопкой ★ «Лучшая»;
  инвертор — производитель → 12 / 24 / 48 В → модель (гибрид со своими MPPT или без MPPT);
  АКБ — тип × число сборок (в сборке последовательно — по напряжению системы, само).

## База оборудования

- Панели — 21,7 тыс. моделей, 260 производителей (база CEC/NREL + паспорта популярных серий,
  которых там нет). В описании видно, откуда данные: «паспорт ✓» / «база CEC» / «≈ типовые».
- Инверторы — 241 (12 В — 60, 24 В — 70, 48 В — 111), гибриды и без MPPT.
- MPPT-контроллеры — 30, АКБ — 38 (готовые, сборки 16S, ячейки, свинец).
- Модели с пометкой «≈ не проверено» — из каталога, не из паспорта: сверяйте с табличкой.

## Страницы

- 📊 **Прогноз выработки** — по часам и месяцам, куда уходит энергия, проверки.
- 🏠 **Покрытие дома** — сколько % потребления закрывает станция, сколько из сети и за сколько,
  в какие месяцы можно жить без сети, что докупить.
- 🔌 **Когда на горсеть** — заряд АКБ по 10 минутам: когда АКБ садится и дом переходит на сеть,
  кВт·ч из сети по месяцам, серия пасмурных дней подряд.
- 💰 **Зелёный тариф (Украина)** — окупаемость домашней СЭС: станция и почасовая выработка
  берутся из ⚙ Настроек; область и ОСР по координатам, плата ОСР, 1/2/3 зоны, взаимозачёт, налог,
  тариф до 2030, деградация, «каждый год как худший», «без продажи в сеть»; смета, цены, документы
  и шаги; отчёт HTML, смета CSV.
- 🌤 **Погода** — сейчас, по часам и на 6 дней (Open-Meteo, без ключа), поиск города;
  «Выработка по прогнозу погоды» — тот же расчёт станции на каждый день.
- 🌌 **Небо** — путь Солнца (сегодня / 22 июня / 22 декабря), Луна с фазой, звёзды и созвездия,
  облака по погоде; ⛶ на весь экран.
- ⚙ **Настройки станции** (профили 📂 / 💾), 📐 угол / азимут, 🧵 провод, 🌐 данные солнца,
  🔄 обновление с GitHub, 🎨 цвета.

**📍 Регион 5 лет** (рядом с «☀ Ясно · ⛅ Средний · ☁ Пасмурно»): реальная погода по часам за
последние 5 полных лет для точки станции (Open-Meteo ERA5 или PVGIS-SARAH3) → средний день каждого
месяца, ясные / пасмурные дни, часы солнца, разброс выработки по годам. Загружается один раз
(нужен интернет), дальше хранится в `config.json`.

Одна формула Солнца (NOAA) для расчёта, неба и восхода / заката; место и пояс (летнее время по
правилу ЕС) — из настроек станции. Без интернета всё, кроме погоды и загрузок, работает.
Правый клик — меню почти везде (таблицы, графики, журнал, поля, выбор модели).

## Профиль станции

Станция по умолчанию (новый запуск без `config.json` или ⚙ Настройки → ↺ По умолчанию) и пример
профиля `моя_станция_Краматорск.json` (⚙ Настройки → 📂 Открыть): гибрид 11 кВт с 2 входами MPPT,
два поля по 9 панелей 565 Вт, отдельный MPPT с полем из 3 панелей, АКБ 16S × 4 сборки
(21,5 кВт·ч), дом 1000 кВт·ч в месяц, без горсети. Свою станцию сохраните в свой профиль (💾).

## Обновление с GitHub

Боковая панель → 🔄 Обновление. Нужен токен GitHub «только чтение» (fine-grained, репозиторий
Solar_calc, Contents: Read-only) — кнопка «?» рядом с полем токена покажет по шагам, как его получить.
Новая версия проверяется сама (через 30 с после запуска и дальше раз в 12 ч; можно выключить),
нашлась — «⬆» на кнопке страницы и «⬆ X.Y.Z» в строке состояния. Ставится только по вашей кнопке:
старый код, которого нет в новой версии, стирается; `config.json`, профили станции (`*.json`) и
журналы не трогаются; затем перезапуск. Обновляется только программа на Python — собранный EXE
сам не обновляется. «Что нового» берётся из журнала в шапке `solar_calc.py`.

## Сборка EXE

`build_exe.bat` → `dist\solar_calc.exe` (PyInstaller по `solar_calc.spec`, затем самопроверка EXE).

## Точность

Не учитываются частичная тень по панелям, снег, полный заряд АКБ (контроллер сам снижает ток) и
деградация панелей. Сверьте с реальными показаниями и подгоните «Поправка по факту» и
«пасмурно = %».
